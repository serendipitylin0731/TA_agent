# 知页 TA Agent 项目汇报提纲

1. **引入。** 教师或学生提出问题后，常要在不同教材中反复查找；普通生成式答案缺少书名和页码，难以核验。
2. **方案。** 知页提供 Chat 问答、查询原文、阅读原版教材三个入口。演示截图来自当前项目运行页面。
3. **工作方式。** 已接入 113 册教材，分布于初高中 20 个学科目录位。系统将 PDF 转为保留页序的 Markdown 和分页索引，以多词组、模糊检索找到相关页，再由模型整理成回答，附可点击的教材页码；未检索到足够证据时单独标注。
4. **网页演示。** 在演示电脑启动服务后，点击 PPT 中的 `http://127.0.0.1:8000/`。可依次展示 Chat 问答、按书合并的原文结果和双页阅读。
5. **优势与便利。** 来源可追溯；自然问句与错别字更容易命中；跨页信息可整合；最近十个聊天会话与十次检索便于继续学习。
6. **未来扩展。** OCR 补齐扫描页；按授权扩充教材版本；图文联合检索；根据年级与目标提供个性化学习支持。以上为后续规划，不应作为已实现功能介绍。
