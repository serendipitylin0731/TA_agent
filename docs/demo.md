# 演示脚本

## 演示前检查

在项目根目录执行：

```bash
source .venv/bin/activate
python scripts/sync_keben.py --dry-run
python scripts/sync_general_tech.py
uvicorn app.main:app --host 127.0.0.1 --port 8765
```

首次同步大量教材需要较长时间；演示前确认 `http://127.0.0.1:8765/api/status` 的 `textbook_count` 大于 0。要演示 AI 回答，在 `.env` 中配置模型服务的 API Key 并重启服务。演示资料仅在本机使用。

## 三分钟主线

1. **查询原文**：进入“查询原文”，选择初中、语文，搜索“济南的冬天”。打开教材命中结果，指出书名、版本和“PDF 第 n 页”。独立的大屏阅读界面直接展示对应 PDF 页；点击顶部返回按钮回到检索结果。说明 PDF 页序可能不同于教材印刷页码。
2. **Chat 来源问答**：进入“Chat 问答”，选初中、语文和“来源问答”，提问“《济南的冬天》在七年级语文教材的哪一课？请给出依据。”展示回答下方的“参考资料与定位”，其中包含书名、册次和 PDF 页序；点击可回到原版教材。若本地检索没有证据，系统应说明缺资料，不猜页码。
3. **阅读原版教材**：进入“阅读教材”，按初中、语文筛选，选择七年级上册。展示完整 PDF 在页面内阅读，也可从教材目录看到已接入的册数。

## 补充展示

- 在“查询原文”切换到“联网资料”，搜索一个知识点，导入开放条目后展示许可与原文链接。该资料在搜索和 Chat 中标记为开放网络资料。
- 在原文检索框输入“济南的”，展示教材词项补全；输入“济南的东天”，展示基于本地教材内容的错别字建议“济南的冬天”。
- 切换“模型常识”，询问尚未接入教材的内容，观察回答开头的“未核对教材”标记。
- 在“资料管理”展示来源、册次、许可、片段数量；讲解教材 PDF 只存本机，GitHub 仅保存代码、目录和同步流程。

## 评委可能追问

| 问题 | 回答要点 |
| --- | --- |
| “部编版”是否覆盖所有学科？ | 教育部统编教材覆盖语文、历史、道德与法治/思想政治；其他学科在目录中明确标记人教版，浙江高中信息技术为浙教版、通用技术为苏教版。 |
| 引用页码可靠吗？ | 直接由解析 PDF 的页索引产生，并跳转到同一原件。它是 PDF 物理页序，印刷页码需要人工或后续算法映射。 |
| 模型会编造资料吗？ | 来源问答只把检索到的片段提供给模型，并要求引用；无片段时不调用模型。生成内容仍需教师核对，可一键回到原件。 |
| 教材能公开分享吗？ | 本地演示与代码仓库分开。PDF 没有提交 GitHub；公开部署前要取得相应授权。 |
