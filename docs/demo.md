# 演示脚本

1. 进入 Chat，提出“函数的定义是什么？”。展示直接的解释，以及答案下方所引用的八年级下册教材位置；点击引用，双页阅读器从命中页打开。
2. 提出“中国古代科举制度如何发展？”，观察隋、唐、宋和清末多个教材页被综合引用。
3. 提出“量子计算机如何制造？”，展示模型直接回答和下方单独的“教材库未检索到合适内容”提示。
4. 进入查询原文，搜索“椭圆的第二定义”，展示按书合并的关键页码；点击整张卡片打开第 122 页，用方向键及下一命中按钮翻页。搜索“光合做用的过程”演示错别字纠正。
5. 进入阅读教材，先选初中区或高中区，再选学科，展示按册次排序的封面；打开教材后确认从第一页开始。
6. 刷新页面，检查最近 10 条聊天和检索记录；点击侧栏介绍卡片查看设计初衷、功能、教材覆盖和联系方式。
7. 说明教材文件仅保存在本机，不进入 GitHub；普通用户页面和公开 API 均没有资料管理功能。
